5 · Features

Functional

C Create from script/idea → AI-generated video
E Edit uploads: cut silences/filler, dead-air removal
T Word-level captions, burned-in (Submagic-style)
R Auto-reframe 9:16 / 1:1 for social
H Highlights → short reel (rank moments)
⌘ ⌘K agent: plan + run multi-step edits, reversible
X Export real MP4 · download

Non-functional

✓ HTTPS, auto-renewing TLS
✓ Fail-soft agent (deadline + fallback, never crashes)
✓ Isolated compute (Railway) — renders off the shared box
✓ 46 tests, strict TS, typechecked CI
~ Async jobs + progress (no request blocking)
~ Resource caps / queue for heavy renders
~ Observability: job logs + render metrics (planned)

6 · Deployment

Model
Edge on Hetzner CO VPS (nginx + web + agent API). Compute on Railway (worker: ffmpeg/ASR/gen). DNS on Namecheap, TLS via Let's Encrypt.
Prerequisites
ANTHROPIC + OPENAI + FAL keys (server-side), Railway project, GitHub Actions secrets (HETZNER_CO_*), domain A record.
Workflow
Push to main → CI (typecheck/test/build) → deploy web/agent to VPS (rsync+systemd) · worker to Railway (Docker). Manual first deploy validated; auto-deploy pending secrets.
